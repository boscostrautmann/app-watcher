# app-watcher
App Watcher est un script Bash pour surveiller et gérer les applications sur macOS via JAMF.

## Prérequis
- macOS avec JAMF installé.
- `jq` pour parser les réponses JSON (installez avec `brew install jq`).
- Droits administrateur pour l’installation.
